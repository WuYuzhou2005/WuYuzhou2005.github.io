# Yuzhou Wu — Academic Website

Static academic website with separate Home, Research, CV, and Contact pages.

- `index.html`: introduction and reserved portrait space.
- `research.html`: current collaboration and research paper, using the supplied CV.
- `cv.html`: full HTML CV with an optional PDF download.
- `contact.html`: contact details.
- `assets/styles.css` and `assets/site.js`: shared styling and footer year.
- `Yuzhou_Wu_CV.pdf`: the real uploaded CV; all download links use `/Yuzhou_Wu_CV.pdf`.

To add a portrait, upload `assets/portrait.jpg` and replace the `portrait-slot` div in `index.html` with `<img class="portrait-slot portrait-photo" src="/assets/portrait.jpg" alt="Yuzhou Wu">`. No portrait has been fabricated.

The CV content comes from the owner's supplied LaTeX. ASTAM recognition is pending; the research paper is submitted, not accepted. Pages settings are unchanged.
